# VINEET FURNISHINGS ERP

## What is included
- Professional collapsible navigation menu
- Dashboard with production KPIs
- Master Data for Parties, Designs, Beams, Shades and Sizes
- Excel export foundation
- Loom Program form for Loom 1-52
- Automatic design beam, shade, size and thread display
- L-shaped article representation
- Production History and Analytics pages
- Supabase-ready SQL schema using consistent BIGINT IDs

## Run on your computer
1. Install Node.js 20 or newer.
2. Open Terminal inside this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local address shown in Terminal.

## Connect Supabase
1. Open Supabase SQL Editor.
2. Paste and run `supabase/schema.sql` once.
3. Copy `.env.example` to `.env`.
4. Add your Supabase Project URL and anon key.
5. Restart `npm run dev`.

## Upload to GitHub
Upload every file and folder in this project. Keep this README file.

## Deploy on Vercel
Import the GitHub repository in Vercel. Add the two environment variables from `.env.example` in Vercel Project Settings, then deploy.
